# Paul Hansen's terminal

My personal fork of [wezterm](https://wezterm.org/)

I don't plan on upstreaming this, mainly because of effort required and I know Wez has been away from his project for awhile so there's low chance of features being merged. This is more of just getting the fixes I want in a way I can reuse them across my machines.

Feel free to upstream anything you want though.
